# ps4catalog

Заплатки каталога для приложения ps4installer (оффлайн-магазин игр для PS4).

Здесь нет кода: заплатки лежат во вкладке **Releases**. Каждый выпуск содержит `index.json` (номер последней заплатки, размеры, SHA-256) и файлы `catalog_N.json` / `catalog_N.pak`.
Приложение само берёт `releases/latest/download/index.json`, скачивает недостающие файлы и проверяет их суммы.

Как готовить выпуск - см. [PATCHES.md](PATCHES.md).
