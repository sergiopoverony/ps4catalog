# Обновление каталога: заплатки и выпуск на GitHub

Все команды выполняются в WSL из папки проекта: `cd ~/ps4installer`.
Дамп и таблица лежат в `D:\TORRENT\RUTRACKER_BASE\` (в WSL это `/mnt/d/TORRENT/RUTRACKER_BASE/`).
Папка `data` - рабочая: в ней основной каталог `catalog.json` + `catalog.pak`, все прежние заплатки `catalog_N.json` / `catalog_N.pak` и кэш картинок `.media_cache`.

**Папку `data` не удалять и не терять** (делай её копию). Новая заплатка считается относительно основного каталога и всех прежних заплаток: без них скрипт не знает, что уже есть у людей.

---

## 1. Обычное обновление (каждый месяц, вышла новая выгрузка)

**1.1. Обновить проект**
```
cd ~/ps4installer
git pull
```

**1.2. Разобрать новую выгрузку в таблицу** (от получаса до часа и больше; имя новой таблицы другое, чтобы не затереть старую)
```
python3 tools/rutracker_table.py /mnt/d/TORRENT/RUTRACKER_BASE/rutracker-ДАТА.xml.xz /mnt/d/TORRENT/RUTRACKER_BASE/ps4_games_new.csv
```

**1.3. Сделать заплатку** (только то, что изменилось с прошлого раза)
```
python3 tools/make_patch.py data /mnt/d/TORRENT/RUTRACKER_BASE/ps4_games_new.csv
```
- Результат: `data/catalog_N.json` (и `catalog_N.pak`, если появились новые игры с картинками). N - следующий свободный номер (2, 3, 4 ...).
- Если изменений нет, скрипт так и напишет, и файлов не будет.
- Картинки новых игр качаются из интернета. Не качать: добавь в конец команды `--no-media` (новые игры вне каталога магазина останутся без обложек).
- Пока ничего не уходит людям: заплатка лежит только в `data`.

**1.4. Подготовить выпуск**
```
python3 tools/make_release.py data release
```
- В папке `release` появятся `index.json` (номер последней заплатки, размеры, SHA-256, отпечаток основного каталога) и **все** заплатки с номера 2.
- Каждый раз выкладываются все заплатки, а не только новая: приложение, которое давно не обновлялось, догоняет по порядку.

**1.5. Выложить на GitHub**
1. Открыть https://github.com/sergiopoverony/ps4catalog, вкладка **Releases**, **Draft a new release**.
2. Tag: новый, например `patch-3` (по номеру последней заплатки). Название любое.
3. Перетащить в окно **все** файлы из папки `release` (в том числе `index.json`).
4. **Publish release** (не draft и не pre-release: приложение берёт ссылку «latest»).

**1.6. Проверить**
- Адрес `https://github.com/sergiopoverony/ps4catalog/releases/latest/download/index.json` должен открываться в браузере и показывать номер последней заплатки.
- На приставке: запустить приложение с интернетом. В `/data/ps4installer_app/log.txt` будут строки:
  - `ui: заплатки из интернета: скачано заплаток: N (будут применены при следующем запуске)`;
  - после перезапуска приложения: `ui: заплатки каталога: применено N (последняя M)`.
- Заплатка применяется при следующем запуске приложения, не сразу.

---

## 2. Заплатку можно положить на приставку вручную (без GitHub)

Скопировать `data/catalog_N.json` и `data/catalog_N.pak` в `/data/ps4installer_app/catalog/` рядом с основным каталогом и перезапустить приложение.

---

## 3. Полная пересборка каталога (не заплатка)

Нужна, если поменялась логика сопоставления игр или хочется собрать всё заново.

```
cd ~/ps4installer && git pull
python3 tools/rutracker_table.py /mnt/d/TORRENT/RUTRACKER_BASE/rutracker-ДАТА.xml.xz /mnt/d/TORRENT/RUTRACKER_BASE/ps4_games.csv
python3 tools/merge_torrents.py data /mnt/d/TORRENT/RUTRACKER_BASE/ps4_games.csv --cache-only
```
- `--cache-only`: картинки только из кэша, в интернет не ходит (быстро). Без этого флага недостающие картинки докачаются.
- Результат: новые `data/catalog.json` и `data/catalog.pak` (около 830 МБ).
- Положить оба файла на приставку в `/data/ps4installer_app/catalog/`.
- **Старые заплатки после этого не нужны и не подойдут:** удалить `data/catalog_N.*` и такие же файлы на приставке (приложение всё равно не поставит заплатки, у которых отпечаток основного каталога другой). Следующая заплатка получит номер 2.
- Чтобы людям пришло обновление после полной пересборки, они должны получить новый основной каталог (файлом). Заплатки новый каталог не заменяют.

## 4. Что где лежит

| Что | Где |
|---|---|
| Основной каталог и заплатки (рабочая папка) | `~/ps4installer/data` |
| Кэш картинок | `~/ps4installer/data/.media_cache` |
| Таблица игр | `/mnt/d/TORRENT/RUTRACKER_BASE/ps4_games*.csv` |
| Папка выпуска для загрузки | `~/ps4installer/release` |
| Каталог на приставке | `/data/ps4installer_app/catalog/` |
| Журнал приложения на приставке | `/data/ps4installer_app/log.txt` |
| Репозиторий выпусков | https://github.com/sergiopoverony/ps4catalog |

## 5. Если что-то не так

- **Приложение не скачивает заплатки.** В журнале приложения ищи строки `https:` и `ui: заплатки`. Нет интернета: «интернета нет, проверку пропускаем». Ошибка рукопожатия или сертификата: код после `sceHttpSendRequest`. Загрузка по HTTPS пока не проверена на настоящей консоли.
- **«заплатки сделаны для другого основного каталога».** На приставке другой `catalog.json`, чем в `data` при выпуске. Положить на приставку тот же основной каталог или сделать выпуск заново из той же папки `data`.
- **«не сошлись размер или SHA-256».** Файл в выпуске не тот или повреждён: собрать `release` заново и загрузить все файлы целиком.
- **Выпуск уже выложен, а в нём ошибка.** Выложить новый выпуск с новым тегом (последний выпуск и есть «latest»); старый можно удалить на GitHub.
